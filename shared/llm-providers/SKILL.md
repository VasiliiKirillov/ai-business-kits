# Провайдеры LLM: ключи, модели, геоблок, прокси

Общий скилл для любого кита, который вызывает языковую модель. Имена переменных `.env` (в ките `intake-bot` это `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL_PARSE`, `LLM_MODEL_CHAT`, `LLM_BASE_URL`, `LLM_PROXY`) смотри в `.env.example` своего кита.

## Что нужно от человека

- Выбор провайдера (или согласие на твою рекомендацию) и аккаунт у него.
- Готовность пополнить баланс: нужен **официальный API-ключ с оплатой по использованию**, а не подписка вроде "Pro" или "Plus".
- Ключ человек вписывает в `.env` сам.

## Шаги

1. **Выбор провайдера.** Объясни простыми словами:

| Провайдер | Когда |
|---|---|
| Anthropic | хорошее качество диалогов и чтения фото, быстрые дешевые модели для разбора |
| OpenAI | привычный вариант, широкий выбор моделей |
| DeepSeek | заметно дешевле, хорош для текста |
| OpenRouter | один ключ ко многим моделям, удобно пробовать |
| Ollama | модель на своей машине, бесплатно, но нужен мощный компьютер; на слабом VPS не ставить |
| свой (custom) | любой сервис с API, совместимым с OpenAI, через `LLM_BASE_URL` |

2. **Ключ.** Человек заводит аккаунт и создает API-ключ в консоли провайдера, вписывает в `.env`. Не проси ключ в чат. Если пишешь в `.env` сам, не печатай значение обратно.
3. **Модели.** Нужны две роли: быстрая дешевая модель для разбора сообщений (вызывается на каждую реплику) и модель для ответов клиенту. Имена моделей меняются: проверь актуальный список у провайдера в интернете, не угадывай. Если в ките можно оставить пустыми, возьмутся значения по умолчанию, но сверься со списком.
4. **Проверка с сервера.** До запуска проверь, что сервер достает до API провайдера:

   ```bash
   curl -sI https://api.anthropic.com | head -1
   curl -sI https://api.deepseek.com | head -1
   curl -sI https://api.openai.com | head -1
   ```

   Любой HTTP-ответ (200, 401, 404) значит, что дорога открыта.
5. **Геоблок.** У ряда провайдеров API закрыт для некоторых стран. Признаки: 403 с текстом о стране, `country not supported`, таймаут, обрыв. Решения: другой регион сервера (Европа или США) или прокси.
6. **Прокси.** Задается в `.env` (`LLM_PROXY=http://<proxy-host>:<port>`, поддерживаются http(s) и socks; для socks может понадобиться `httpx[socks]`). Прокси человек покупает или поднимает сам, это платное: спроси согласие.

## Проверка

- Запрос к провайдеру из ожидаемого места запуска (локально или с сервера) возвращает ответ модели, а не 401, 403 или таймаут.
- Ключ лежит только в `.env` с правами `600`, в репозитории его нет.

## Диагностика

- `401`, `403`, `invalid api key`: проверь ключ, баланс у провайдера и что ключ официальный API, а не подписка.
- Таймауты или `country not supported`: геоблок, шаги 4-6.
- Ответы медленные: поставь более быструю модель на роль разбора.

## Подводные камни

- Только официальные API-ключи. Токены подписочных OAuth-входов провайдеров могут быть ограничены в сторонних приложениях.
- Не клади ключи в репозиторий, не пересылай по мессенджерам.
- На слабом VPS не ставь локальные модели.
- Следи за балансом: когда он кончается, кит молча перестает отвечать.
