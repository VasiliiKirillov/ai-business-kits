# Фото позиций

Положи сюда фото позиций каталога: `<ключ>.jpg` (или png, jpeg, webp).

Ключ - название позиции, переведенное в латиницу (транслитерация), строчными буквами и только буквы и цифры, без пробелов и знаков.
Например, `Honda PCX 160` -> `hondapcx160.jpg`, `Gel Manicure` -> `gelmanicure.jpg`, `Маникюр классический` -> `manikyurklassicheskiy.jpg`.

Бот отправляет фото один раз, когда клиент выбрал позицию, и по просьбе клиента.
Нет файла - бот обходится без фото. Папку можно сменить переменной `PHOTOS_DIR`.
