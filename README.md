# ai-business-kits

Готовые AI-автоматизации для малого бизнеса. Каждая автоматизация (кит) лежит в своей папке: набор скиллов для AI-агента и, где нужно, готовый код. Ты отдаешь репозиторий своему агенту, говоришь, что хочешь автоматизировать, и он по шагам, сам выполняя команды и объясняя каждый шаг, все настраивает под тебя.

## Киты

| Кит | Для кого | Что делает | Статус |
|---|---|---|---|
| [intake-bot](intake-bot/README.md) | прокат, запись к мастеру, заказы, бронирования | Telegram-бот принимает заявки, проверяет наличие и цены, шлет менеджеру карточку с кнопкой "Подтвердить", собирает договор и запись в таблицу | готов |

Новые киты будут добавляться сюда.

## Как пользоваться

Скорми репозиторий агенту и скажи, что хочешь автоматизировать. Например: "настрой мне приемщика заявок для моей мастерской".

### Claude Code

```bash
git clone https://github.com/VasiliiKirillov/ai-business-kits
cd ai-business-kits
claude
```

В сессии опиши задачу. Агент прочитает `CLAUDE.md` и `AGENTS.md`, выяснит, что тебе нужно, выберет подходящий кит и пойдет по его шагам.

### Codex, Cursor и другие агенты

Открой папку репозитория в агенте с доступом к командной строке. Codex и Cursor читают `AGENTS.md` автоматически. Если твой агент этого не делает, напиши: `прочитай AGENTS.md в этой папке и действуй по нему, я хочу автоматизировать <задача>`.

## Структура

```
AGENTS.md      инструкция для агента: как выбрать кит и общие правила
CLAUDE.md      отсылка на AGENTS.md для Claude Code
shared/        общие скиллы для всех китов
  server-setup/      VPS, SSH-ключи, пользователь, Python, systemd, логи
  google-workspace/  Google OAuth, Sheets, Docs, Drive
  llm-providers/     ключи моделей, выбор провайдера, геоблок, прокси
intake-bot/    кит: AI-приемщик заявок (скиллы, шаблон бота, README, AGENTS.md)
```

## Что понадобится от тебя

У каждого кита свой список в его README. В общем случае: аккаунты в нужных сервисах, ключ API языковой модели (официальный, с оплатой по использованию, а не подписка), при необходимости сервер от 5 долларов в месяц и час-два времени на вопросы о твоем бизнесе.

## Чего здесь нет

Нет ничьих персональных данных, токенов, ключей, адресов серверов и ссылок на чужие таблицы. Все примеры выдуманные. Секреты ты вводишь у себя в файл `.env`, в репозиторий они не попадают.
